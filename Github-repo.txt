This project demonstrates basic Git version control operations using a simple Python application. The objective was to initialize a Git repository, track files, create commits, and review the repository history.


## Project Structure

 

```text

## Python Script

### hello_world.py

```python

print('git is Awesome!')

### Expected Output

 

```text

git is Awesome!

```

 

## Git Commands Executed

 

### Verify Git Installation

 

```bash

git --version

```

 

Output:

 

```text

git version 2.54.0.windows.1


 

### Initialize Git Repository

```bash

git init

 

### Check Repository Status

```bash

git status

```

 

Output:

 

```text

On branch master

 

No commits yet

 

Changes to be committed:

new file: hello_world.py

```

### Add File to Staging Area
 

```bash

git add hello_world.py
```

### Create Initial Commit

```bash

git commit -m "Hello world"

```
Output:


```text
[master (root-commit) bc391a0] Hello world

1 file changed

create mode 100644 hello_world.py

```

 

### Verify Commit History

 

```bash

git log

```

 

Output:

 

```text

```

```bash

git --version
